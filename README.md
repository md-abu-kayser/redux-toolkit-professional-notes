# Redux Toolkit Professional Notes

A structured, topic-by-topic set of notes for learning and mastering **Redux Toolkit (RTK)** and **RTK Query**, from fundamentals to production patterns.

## Structure

- `00-prerequisites/` — React, state management, and Flux/Redux background
- `01-getting-started/` — Setup and store configuration
- `02-slices-and-reducers/` — createSlice, actions, Immer
- `03-selectors/` — Memoized and composed selectors
- `04-async-logic-and-middleware/` — Thunks, createAsyncThunk, middleware
- `05-rtk-query/` — Data fetching, caching, mutations, auth
- `06-advanced-state-patterns/` — Entity adapters, SSR, dynamic reducers
- `07-typescript-integration/` — Typing store, hooks, thunks, RTK Query
- `08-testing/` — Unit/integration testing for slices, thunks, components
- `09-patterns-and-best-practices/` — File structure, error handling, conventions
- `10-performance-optimization/` — Rerenders, profiling, transient updates
- `11-migration-and-upgrades/` — Migrating from classic Redux/Saga
- `12-real-world-projects/` — Task manager, e-commerce, social feed, auth, dashboard
- `13-code-snippets/` — Ready-to-use TypeScript snippets
- `14-resources-cheatsheets/` — API reference, interview questions, further reading

## How to use

Each `.md` file is a self-contained note: overview, key points, example, references. Fill them in as you learn, or use them as a personal reference while building projects.
