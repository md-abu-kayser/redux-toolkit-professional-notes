# Contributing

Thanks for considering a contribution to these Redux Toolkit notes!

## How to contribute

1. Fork the repo and create a branch for your change.
2. Follow the existing folder/file naming convention (numbered, kebab-case).
3. Keep each note focused on a single topic.
4. Include a runnable code example where relevant.
5. Open a pull request using the provided template.

## Style guide

- Use clear, concise headings.
- Prefer TypeScript in code examples.
- Link to official docs where useful.
